## 原始需求复述

对已跑通的 AI 研究工作台前端做一次 UI 优化，共 6 条：

1. **R1 统一视觉规范**：配色、字号层级、圆角、阴影、间距与栅格对齐，各页面风格一致。
2. **R2 尺寸与分区**：调整容器与卡片尺寸，避免过大留白或元素挤压；内容按信息层级分区，区块间距与对齐整齐，杜绝杂乱堆叠。
3. **R3 可读性**：标题层级清晰；表格 / 表单 / 按钮布局规整；主要操作入口位置明确。
4. **R4 面向普通客户的易用性**：首页或醒目位置用简短文案说明项目是做什么的；核心功能入口一目了然；关键操作提供引导提示，无需培训即可上手。
5. **R5 状态补齐**：空状态、加载态、错误提示。
6. **R6 响应式**：兼容桌面与移动端。

## 一、产品目标

**一句话目标**：在不改动任何功能与路由的前提下，把 9 个页面收敛到一套统一的视觉与交互规范，并把首页重构为"30 秒看懂 + 一键进入"的入口，使**第一次打开网站的普通客户无需培训即可完成一次研究**。

拆成 3 个正交子目标：

| 目标 | 判定标准 |
| --- | --- |
| G1 规范统一 | 全站同类元素（卡片 / 标题 / 按钮 / 表单行 / 状态标签）只存在 **1 种**主实现 + 有限变体；字号、圆角、间距、阴影全部来自 CSS 变量令牌，无硬编码散值 |
| G2 主操作可见 | 每个页面的主操作入口在**首屏之内**（1440×900 桌面 / 390×844 移动）不滚动即可看到 |
| G3 状态完备 | 每个会发起异步请求的页面都有「空 / 加载 / 错误（含重试）」三态，且三态样式统一 |
